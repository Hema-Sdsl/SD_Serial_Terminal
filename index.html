Help & shortcuts

1 · Connect

  • Serial: click Add port… once per adapter (the browser only shows ports you allowed), choose baud, click Connect. Bluetooth COM ports are hidden unless you tick “Show Bluetooth & other COM ports”.
  • BLE: pick a service profile, click Scan & Connect. Write / notify characteristics are chosen automatically; change them under Data routing or with the TX / RX buttons in the GATT table.

2 · Send

  • HEX AA 55 01 · AA5501 · 0xAA,0x55   DEC 170 85 1   ASCII text with \r \n \t \0 \xFF \\
  • The grey line under the box shows the exact bytes before sending. Wire order: data → checksum → line end.
  • Enter send · Shift+Enter new line · ↑/↓ history · Repeat sends periodically · Send file… sends raw file bytes.

3 · Commands, auto-reply, tools

  • Save anything as a command (with group, format, line end, checksum). Click to send, Alt+1…9 for the first nine. Serial and BLE keep separate lists.
  • Auto-reply answers automatically when RX contains a pattern.
  • Tools: Modbus RTU builder, converter with checksums, number→bytes, log highlight words.

4 · Log

  • Switch ASCII / HEX / DEC / HEX+ASCII any time. ESP-IDF levels and ANSI colours are shown.
  • Ctrl+F search, Enter/Shift+Enter next/previous, filter button shows only matches.
  • Pause freezes the view while data is still captured. Record streams the log to a file. Plot graphs numbers from RX lines.
  • Double-click a line to copy it. Ctrl + mouse wheel over the log (or the − / + buttons) changes the text size.

5 · Layout

  • Drag the thin lines between panels to resize them (double-click resets). Hide panels with the buttons at top-right. The send box can be stretched by its corner.

Use Chrome or Edge on desktop. All settings, commands and layout are saved in this browser — use Export all settings to share them with the team.
